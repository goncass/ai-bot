# Bot de IA

Bot de conversa que usa um LLM local (Ollama) para responder.

## Como correr

1. Instala o Ollama: https://ollama.com
2. Corre: `ollama run llama3.2`
3. Instala: `pip install requests`
4. Corre: `python bot.py`

## O que aprendi

- usar `requests` para falar com uma API
- enviar e receber JSON
- `while True` para loop de conversa
- `try/except` para tratar erros
